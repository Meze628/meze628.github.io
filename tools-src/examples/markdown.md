## 数学公式

两种行内写法都能渲染：$a^2+b^2=c^2$，以及 \(\sum_{i=1}^{n} i=\frac{n(n+1)}{2}\)。

独立公式适合更完整的推导：

$$
\begin{aligned}
S_n &= 1+2+\cdots+n \\
    &= \frac{n(n+1)}{2}
\end{aligned}
$$

\[
\int_0^1 x^2\,\mathrm{d}x=\frac{1}{3}
\]

## 文字、列表与表格

一段适合阅读的中文，需要合适的字号和行距。这里支持 **加粗**、*斜体*、~~删除线~~，也支持 [回到博客](https://meze0.top)。

> 写作时关注内容，导出时再调整纸张上的留白。

- 使用思源黑体或思源宋体。
- 设置正文和代码各自的字号。
- 公式保留矢量图形，正文保留可选择的文字。

| 内容 | 示例 | 说明 |
| :--- | :---: | :--- |
| 行内公式 | $x_i^2$ | 随文字排列 |
| 求和 | $\sum_{i=1}^{n}i$ | 适当留出行高 |
| 代码 | `long long` | 等宽字体 |

## 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
typedef long long ll;

int main(){
    ll n;
    cin>>n;
    cout<<n*(n+1)/2<<'\n';
    return 0;
}
```
